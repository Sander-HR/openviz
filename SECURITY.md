# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Contact the repository maintainers privately through the security contact configured for the GitHub repository.

Include:

- A description of the vulnerability
- Reproduction steps or a proof of concept
- Affected versions or components
- Any suggested mitigation

We will acknowledge reports as soon as practical and coordinate disclosure after a fix is available.

## Security expectations

Never commit credentials, tokens, private keys, `.env` files, or production data. Review dependency and database changes carefully before merging.
