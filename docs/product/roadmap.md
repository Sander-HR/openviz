# OpenViz Roadmap

This document describes product direction at a high level. Detailed implementation work belongs in the numbered specifications under [`specs/`](../../specs/).

## Completed

- Studio canvas with drawing tools and layers
- Workbench node-based editor
- Dashboard and project management
- Authentication
- ComfyUI integration and batch generation
- Undo/redo and keyboard shortcuts

## In progress

- Real-time collaboration
- Animation workflows
- Video generation
- Workflow presets
- Import/export, including project files

## Future

- AI prompt assistance
- Mobile companion experience
- Cloud synchronization
- Plugin system
- Template marketplace

## Planning policy

Active feature decisions are captured in `specs/NNN-feature/`. Completed specifications remain available as implementation and contract history, with their status updated to `Implemented`.
